# Word list

`eff_large.txt` is the EFF Long Wordlist by the Electronic Frontier Foundation
(https://www.eff.org/dice), licensed under CC BY 3.0 US
(https://creativecommons.org/licenses/by/3.0/us/). The four entries that
contain a hyphen (drop-down, felt-tip, t-shirt, yo-yo) are left out so that a
hyphen always separates words, which leaves 7,772 words. Nothing else changed.
